# ecentryUI specifications

These approved documents define the React MVP and later product phases. No application code has been created.

1. [Capability map](CAPABILITY-MAP.md): product boundaries, dependency order, frozen MVP scope.
2. [Architecture and API](SPEC-architecture-and-api.md): source-owned distribution model, repo layout, React conventions, tooling.
3. [Design foundations](SPEC-design-foundations.md): tokens, themes, appearance, responsive and accessibility defaults.
4. [React components](SPEC-react-components.md) and [interaction contracts](SPEC-react-interactions.md): complete component catalog and behavior gates.
5. [Distribution](SPEC-distribution.md): registry, CLI install/diff/update, consumer ownership.
6. [Documentation](SPEC-documentation.md): site structure, live examples, playgrounds, API reference, quality gate.
7. [Roadmap](ROADMAP.md): other frameworks, charts, AI and visual builder after the MVP.

Decisions supplied during review: a consistent ecentryUI API and visual system, with charts after the React component catalog MVP. Consumer-owned source is the required install mode. Native CSS variables and a small optional appearance provider form the theme foundation. The documentation deployment host and exact primitive versions can be selected during planning without changing the product scope.
