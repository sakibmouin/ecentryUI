# Link

Link uses a native anchor for navigation, with focus styling and wrapping for long addresses. Use `external` to indicate a new tab. New tabs receive `noopener noreferrer` automatically.

## Install

```sh
ecentry add link
```

## Preview

<ExamplePanel source={linkSource}>
  <LinkExample />
</ExamplePanel>

## API

`href`, `target`, `rel`, and other native anchor attributes are forwarded. `external` opens a new tab and adds a visual indicator hidden from assistive technology.
