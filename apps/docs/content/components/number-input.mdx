# Number Input

Enter a number, use the step buttons, or drag the scrub handle. Bounds apply to button and scrub changes.

## Install

```sh
ecentry add number-input
```

## Preview

<ExamplePanel source={source}>

</ExamplePanel>

## API

`label` is required. `value` and `onValueChange` control the value; `defaultValue` enables local state. `min`, `max`, and `step` configure bounds and stepping. The native number input supports keyboard entry and form submission. The scrub handle supports pointer dragging and arrow keys.
