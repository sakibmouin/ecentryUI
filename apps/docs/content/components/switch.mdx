# Switch

A labeled on/off control built on a native checkbox. It supports keyboard activation, form submission, validation and reset.

## Install

```sh
ecentry add switch
```

## Preview

<ExamplePanel source={source}>
  <SwitchExample />
</ExamplePanel>

## API

`label` is required. `description` and `error` are linked to the control. Native checkbox props including `name`, `value`, `checked`, `defaultChecked`, `required`, `onChange` and refs pass through. `loading` and `disabled` block interaction. `readOnly` preserves the current value.
