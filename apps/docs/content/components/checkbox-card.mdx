# Checkbox Card

Checkbox Card gives a native checkbox a larger, fully clickable card surface. It keeps label, Space key, form submission, and reset behavior.

## Install

```sh
ecentry add checkbox-card
```

## Preview

<ExamplePanel source={cardSource}>
  <CheckboxCardExample />
</ExamplePanel>

## API

`label` is required. `description` and `error` are connected to the checkbox, and an error sets `aria-invalid`. `loading` and `disabled` prevent activation. `readOnly` preserves the value. Native input props such as `checked`, `defaultChecked`, `name`, `required`, `onChange`, and refs pass through.
