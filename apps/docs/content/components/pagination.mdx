# Pagination

Navigate a paged result set with clear current-page and boundary states.

## Install

```sh
ecentry add pagination
```

<ExamplePanel source={source}>
  <PaginationExample />

## API and accessibility

Set `count` to the total number of pages. Use `defaultPage` for local state or `page` with `onPageChange` for controlled state. `siblingCount` sets the number of pages around the current one. Navigation uses native buttons and announces the current page with `aria-current`.
