# Password Input

A labeled native password field with a show or hide control. The field keeps browser form and reset behavior.

## Install

```sh
ecentry add password-input
```

## Preview

<ExamplePanel source={source}>
  <PasswordInputExample />
</ExamplePanel>

## API

`label` is required. `description` and `error` are linked to the input; an error sets `aria-invalid`. `loading` and `disabled` disable the input and reveal control. Native input props including `value`, `defaultValue`, `required`, `readOnly`, `onChange`, and refs pass through.
