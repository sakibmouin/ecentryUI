# Clipboard

Display a text value and let people copy it with clear success or error feedback.

## Install

```sh
ecentry add clipboard
```

## API and accessibility

`value` is copied exactly and rendered as text. `label` provides the stable, visible copy button name. `disabled` and `loading` prevent copying. `onCopy(value)` reports success; `onError(error)` reports unavailable or denied clipboard access. A polite status announces success or failure, then clears. The native button supports pointer, Enter, and Space. `className`, native div props, and `ec-clipboard__*` classes provide customization. Clipboard access requires a secure context. The demo shows default, disabled, loading, and light/dark states.
