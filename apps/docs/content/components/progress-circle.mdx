# Progress Circle

Show progress as a compact circular indicator.

## Install

```sh
ecentry add progress-circle
```

## Preview

<ExamplePanel source={source}>
  <ProgressCircleExample />
</ExamplePanel>

## API and accessibility

Set `value` and `max` for determinate progress or omit `value` to show an indeterminate ring. `label` names the progressbar; `size` controls its diameter.
