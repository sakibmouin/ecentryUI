# Presence

Keep departing content mounted briefly for an exit animation.

## Install

```sh
ecentry add presence
```

## Preview

<ExamplePanel source={source}>
  <PresenceExample />
</ExamplePanel>

## API and accessibility

Set `present` to show the content. When it becomes false, the wrapper becomes inert and the content fades out over `exitDuration` milliseconds. The default is 150 ms. Returning to present cancels the exit. Reduced-motion preferences and a duration of zero remove the content immediately.
