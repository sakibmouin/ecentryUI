# Progress

Show measurable or indeterminate task progress.

## Install

```sh
ecentry add progress
```

## Preview

<ExamplePanel source={source}>
  <ProgressExample />
</ExamplePanel>

## API and accessibility

Set `value` and `max` for determinate progress, or omit `value` for an indeterminate state. Provide `label` to name the progressbar. Values are clamped to the valid range.
