# Fieldset

Group related controls with a native fieldset and legend.

## Install

```sh
ecentry add fieldset
```

## Preview

<ExamplePanel source={source}>
  <FieldsetExample />
</ExamplePanel>

## API

`label` becomes the legend. `description` and `error` are linked to the group. `disabled` and `loading` disable descendant controls through the native fieldset. Form reset remains native.
