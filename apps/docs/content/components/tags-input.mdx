# Tags Input

Add, edit and remove short text values. Paste comma or newline separated values to add several tags.

## Install

```sh
ecentry add tags-input
```

## API

`label` is required. Use `value` and `onValueChange` for a controlled array, or `defaultValue` for an uncontrolled one. `maxTags` limits additions; duplicate values are ignored without regard to case. `name` submits one form value per tag. `required` requires at least one value. `disabled` and `readOnly` block edits. On a focused tag, press F2 to edit. In the text field, Enter or comma adds a tag and Backspace removes the last tag when empty. Form reset restores `defaultValue`.
