# Badge

Label a state or category with compact text.

## Install

```sh
ecentry add badge
```

## API

`variant` accepts `neutral` (default), `info`, `success`, `warning`, or `error`. `size` accepts `sm` or `md` (default). `loading` adds a spinner and sets `aria-busy`. Provide visible text so meaning is not conveyed by color alone. Badges are plain text by default and do not announce themselves as live status. Native span props, refs, and `className` are supported; the `ec-badge__spinner` class can be styled.
