# Tooltip

Show a short description when a trigger receives hover or keyboard focus.

## Install

```sh
ecentry add tooltip
```

## Preview

<ExamplePanel source={source}>
  <TooltipExample />
</ExamplePanel>

## API

`triggerLabel` and `content` are required. Focus shows the tooltip immediately; hover uses `openDelay` (default 300 ms), and leaving uses `closeDelay` (default 100 ms). Escape dismisses without moving focus. `open` and `onOpenChange` control visibility, or `defaultOpen` sets the initial state. Use Toggle Tip when content contains interactive controls.
