# Text

Text provides token-aware body typography while preserving native semantics. It is a `span` by default; set `as="p"` for a paragraph.

## Install

```sh
ecentry add text
```

<ExamplePanel source={textSource}>

</ExamplePanel>

## API

`as` selects the element. `size` is `sm`, `md`, or `lg`; `weight` is `regular`, `medium`, or `bold`. Native attributes, `className`, and refs pass through.
