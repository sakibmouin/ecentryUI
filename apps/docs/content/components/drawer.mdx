# Drawer

A modal panel that slides in from any edge. Opening it locks page scrolling and places focus inside; closing restores trigger focus.

## Install

```sh
ecentry add drawer
```

<ExamplePanel source={source}>

</ExamplePanel>

## API

`title`, `triggerLabel`, and `children` are required. `placement` accepts `left`, `right`, `top`, or `bottom`. `description` labels the dialog context. Use `open` and `onOpenChange` for controlled state or `defaultOpen` for uncontrolled initial state. Escape, the close button, and backdrop clicks dismiss the panel.
