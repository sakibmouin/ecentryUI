# Center

Center places content on both axes with flex layout. Use `inline` when the centered content should flow with surrounding text. Square and Circle add equal dimensions for icons, badges, and counts.

## Install

```sh
ecentry add center
```

Import `Center`, `Square`, or `Circle` from the installed `components/ui/center/` directory.

## Usage

Give Center a size through `className` or `style` when its content needs room to move. It has no fixed height by default. `inline` changes the layout to `inline-flex` and preserves intrinsic width. Square and Circle accept a `size` in pixels when numeric or any CSS length when a string, such as `size="3rem"`.

Use `as` for a meaningful wrapper element, and provide accessible text or a label for content that is otherwise visual. All three components forward refs and native HTML and ARIA attributes. Flex centering works the same in LTR and RTL.
