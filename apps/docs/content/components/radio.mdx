# Radio

A labeled native radio choice. Group related choices in a fieldset with the same `name`.

## Install

```sh
ecentry add radio
```

## Preview

<ExamplePanel source={source}>
  <RadioExample />
</ExamplePanel>

## API

`label` is required. `description` and `error` are linked to the radio, and errors set `aria-invalid`. Native radio props, including `name`, `value`, `checked`, `defaultChecked`, `required`, `onChange`, and refs pass through. `loading`, `disabled`, and `readOnly` prevent changes.
