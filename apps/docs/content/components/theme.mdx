# Theme

Apply an explicit light or dark appearance to a subtree.

## Install

```sh
ecentry add theme
```

<ExamplePanel source={source}>

## API and accessibility

Use `appearance="dark"` for a dark scope. The default is light, and nested scopes can choose a different appearance. The root sets `data-ec-theme` for ecentryUI token selectors and configures the native color scheme for items such as form controls. Set `withBackground` to apply the scope's foreground and background.
