# Link Overlay

LinkBox positions a semantic LinkOverlay across a card. Other buttons and links inside the card remain independently clickable and keyboard accessible.

## Install

```sh
ecentry add link-overlay
```

## Preview

<ExamplePanel source={linkOverlaySource}>
  <LinkOverlayExample />
</ExamplePanel>

## API

Use LinkBox as the card wrapper and LinkOverlay as the primary anchor with a meaningful accessible name and `href`. Native anchor and wrapper attributes are forwarded.
