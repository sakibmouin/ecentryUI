# Tree View

Browse nested items with expansion, selection and typeahead.

## Install

```sh
ecentry add tree-view
```

<ExamplePanel source={source}>

## API

`label` and `nodes` are required. Each node has `id`, `label`, optional `children`, and optional `disabled`. Use `value` and `onValueChange` for controlled selection, or `defaultValue` for uncontrolled selection. Use `expanded` and `onExpandedChange` for controlled expansion, or `defaultExpanded` for initial open branches. Arrow keys navigate and expand/collapse, Home/End jump to endpoints, typing finds a visible node, and Enter/Space selects.
