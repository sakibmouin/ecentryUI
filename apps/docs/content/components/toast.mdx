# Toast

Announce transient results in a non-blocking queue with optional actions.

## Install

```sh
ecentry add toast
```

## API

`children` is a render function receiving `enqueue(item)`. Each item needs a unique `id` and `title`, and may set `description`, `tone`, `duration`, or `action`. Messages appear in queue order. A `duration` of `0` keeps an item until dismissed; the default is 5000 ms. Timers pause on hover and focus. Use `items` with `onItemsChange` to control the queue, or `defaultItems` for initial messages. Error messages use an assertive alert; other tones use polite status announcements.
