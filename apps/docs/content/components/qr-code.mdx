# QR Code

Encode a short string as a scannable QR symbol.

## Install

```sh
ecentry add qr-code
```

## Preview

<ExamplePanel source={source}>
  <QRCodeExample />
</ExamplePanel>

## API and accessibility

Set `value` to the URL or text to encode and `label` to its purpose. The SVG includes a four-module quiet zone and uses high-contrast fixed colors for scanning. `size` controls the rendered dimensions.
