# Color Picker

Color Picker edits RGB channels, a hex value, and alpha with native inputs. Swatch buttons provide quick selection. Values are canonical uppercase `#RRGGBBAA` strings.

## Install

```sh
ecentry add color-picker
```

## API

`label` names the picker. `value` and `onChange` control it; `defaultValue` enables internal state. Six-digit hex values receive full opacity. `swatches` is an array of six- or eight-digit hex values. `name` writes the selected value to a hidden form input. `description` adds help text. `disabled` and `readOnly` lock editing. Use the native number fields and alpha slider with arrow keys; swatches activate with Enter or Space. Invalid hex text is marked and reverts on blur.
