# Native Select

A labeled browser select with native options, typeahead, keyboard navigation, submission, and reset.

## Install

```sh
ecentry add native-select
```

## Preview

<ExamplePanel source={source}>
  <NativeSelectExample />
</ExamplePanel>

## API

`label` is required and `option` children supply choices. `description` and `error` are linked to the select. `loading` and `disabled` block selection; `readOnly` preserves the current choice. Native select props including `name`, `value`, `defaultValue`, `required`, `onChange`, and refs pass through.
