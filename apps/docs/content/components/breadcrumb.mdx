# Breadcrumb

Show the current page's place in a hierarchy.

## Install

```sh
ecentry add breadcrumb
```

## API

`items` is an ordered list of `{ label, href? }`. Earlier items with `href` are links; the final item is text marked `aria-current="page"`, even if it has an `href`. `separator` defaults to `/` and is hidden from assistive technology. The navigation label defaults to `Breadcrumb` and can be changed with `aria-label`. `loading` sets `aria-busy`. Native nav props, refs, and `className` are supported. The named `ec-breadcrumb__*` classes customize its parts. Links use native keyboard behavior; logical spacing supports RTL.
