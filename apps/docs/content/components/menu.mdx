# Menu

A compact action menu with nested items, typeahead, keyboard navigation and context opening.

## Install

```sh
ecentry add menu
```

<ExamplePanel source={source}>

</ExamplePanel>

## API

`triggerLabel` and `items` are required. Items have `id`, `label`, optional `disabled`, optional nested `children`, and optional `onSelect`. Use `open` and `onOpenChange` for controlled state or `defaultOpen` for uncontrolled initial state. Click or right-click the trigger to open. Arrows move focus, Right opens a submenu, Left returns to its parent, typing finds an item, and Escape closes the menu and restores trigger focus.
