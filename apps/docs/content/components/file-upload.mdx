# File Upload

Choose files through the native picker or drop them onto the upload area. Selected files can be removed before submission.

## Install

```sh
ecentry add file-upload
```

<ExamplePanel source={source}>

</ExamplePanel>

## API

`label` names the file input. Use `files` and `onFilesChange` for controlled selection or `defaultFiles` for local state. `accept`, `maxFiles`, and `maxSize` validate selections. `multiple`, `disabled`, `required`, and native input props pass through. `maxSize` is in bytes.
