# Data List

Present labeled values as a semantic description list.

## Install

```sh
ecentry add data-list
```

<ExamplePanel source={source}>

</ExamplePanel>

## API and accessibility

Pass `items` as ordered `{ label, value }` pairs. The component renders native `dl`, `dt`, and `dd` elements. `orientation` selects `vertical` (default) or `horizontal`, which stacks at narrow widths. `loading` marks the list busy and shows a polite loading message when empty; `emptyMessage` customizes the empty status. Native `dl` props and `className` customize the list, and `ec-data-list__*` classes customize parts. The demo covers both layouts, empty and loading states, and light/dark appearances. No keyboard interaction is needed for static data; interactive values keep their own native behavior.
