# Editable

An inline text editor with explicit Save and Cancel actions. Press Enter to save or Escape to cancel.

## Install

```sh
ecentry add editable
```

## Preview

<ExamplePanel source={source}>
  <EditableExample />
</ExamplePanel>

## API

`label` names the edit button and textbox. Use `defaultValue` for local state or `value` with `onValueChange` for controlled state. `onSubmit` runs after validation. `validate` returns an error message or `undefined`. `disabled` and `readOnly` block editing.
