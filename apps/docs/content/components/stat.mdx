# Stat

Present a key metric with its label and context.

## Install

```sh
ecentry add stat
```

## Preview

<ExamplePanel source={source}>
  <StatExample />
</ExamplePanel>

## API and accessibility

Set `label` and `value` for the metric. `helpText` and `trend` add context; `trendTone` colors the trend. `loading` marks the metric busy. The semantic `dl`, `dt`, and `dd` structure keeps the label and value associated.
