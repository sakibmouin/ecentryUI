# Segmented Control

Choose one option from a compact native radio group. Labels, arrow keys, form submission, and reset retain browser behavior.

## Install

```sh
ecentry add segmented-control
```

<ExamplePanel source={source}>

</ExamplePanel>

## API

`label`, `name`, and `options` are required. Each option has a `label`, `value`, and optional `disabled`. Use `value` and `onValueChange` for controlled selection or `defaultValue` for local state. `description` and `error` describe the group; `required`, `disabled`, and `readOnly` affect selection.
