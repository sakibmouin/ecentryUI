# Combobox

Search a list of choices and select one by pointer or keyboard.

## Install

```sh
ecentry add combobox
```

## API

`label` and `options` are required. Each option has `value`, `label` and optional `disabled`. Use `value` and `onValueChange` for controlled selection or `defaultValue` for uncontrolled selection. `name` submits the selected value. `description`, `error`, `required`, `disabled`, `readOnly`, `placeholder` and `emptyMessage` customize the field. Type to filter; arrows move the active option, Enter selects, Escape closes, and Home/End jump to the first or last enabled match. Form reset restores `defaultValue`.
