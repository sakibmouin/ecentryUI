# Blockquote

Blockquote presents quoted text with semantic markup, readable measure, and
wrapping that remains safe for long content.

## Install

```sh
ecentry add blockquote
```

## API

<div className="api-scroll" role="region" aria-label="Blockquote API" tabIndex={0}>

| Prop                 | Type               | Purpose                      |
| -------------------- | ------------------ | ---------------------------- |
| `as`                 | element type       | Semantic host element        |
| `cite`               | string             | Source URL for the quotation |
| `className`, `style` | native React props | Custom typography overrides  |

</div>

Blockquote forwards refs and native HTML and ARIA attributes. A nested `cite`
element is styled as an attribution line.
