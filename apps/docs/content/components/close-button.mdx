# Close Button

Close Button is a native button with a visible close glyph and an accessible name. The default name is "Close"; give it a context-specific `aria-label` when several close actions appear together.

## Install

```sh
ecentry add close-button
```

## API

`size` is `sm`, `md`, or `lg`. `disabled` and `loading` prevent activation. Loading also sets `aria-busy`. Native button attributes, refs, and `className` pass through. The default button type is `button`.
